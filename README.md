# Week 1 – Event-Driven Programming (Java)

## Project Overview

This repository contains my Week 1 practical work for Event-Driven Programming using Java. The project explores how event-driven systems respond to user actions and other events, and how Java can be used to implement event-driven applications.

The practical activities provided an opportunity to understand event-driven programming concepts, work with event queues and event loops, develop Java calculators, identify and correct event-handling problems, and design a simple event-driven application.

## Activities Completed

### Activity 1: Spot the Components
Identified different real-world event-driven systems and examined their event sources, events, listeners, and handlers. This activity helped demonstrate how different systems respond to events.

### Activity 2: Build the Event Loop
Explored how an event queue and event loop work together to process events. The activity also examined what happens when the event loop becomes blocked and why efficient event handling is important.

### Activity 3: Procedural vs Event-Driven Calculators
Developed two calculator applications in Java: one using procedural programming and another using event-driven programming with Swing. Compared the two approaches and examined how event listeners respond to user interactions.

### Activity 4: Debug the Event Handler
Worked on identifying and correcting common event-handling problems in Java Swing applications, including blocking the Event Dispatch Thread, missing listeners, incorrect thread usage, and memory leaks.

### Activity 5: Design Your Own Event-Driven System
Designed and developed a Library Management System prototype using Java Swing. The design identifies event sources, events, handlers, possible issues, and the flow of events within the system.

### Activity 6: Final Self-Assessment
Reviewed the main concepts covered throughout the practical activities and completed a self-assessment to evaluate understanding of event-driven programming.

## Technologies Used

- Java
- Java Swing
- Java Development Kit (JDK)
- GitHub for project version control and submission

## Learning Outcomes

Through these activities, I explored:

- Event sources, events, listeners, and handlers.
- Event queues and event loops.
- Differences between procedural and event-driven programming.
- Java Swing event handling.
- The importance of the Event Dispatch Thread (EDT).
- Designing and developing simple event-driven applications.

## Conclusion

The Week 1 practical activities provided practical exposure to event-driven programming concepts using Java. They helped develop an understanding of how applications respond to events, how event handlers are implemented, and how event-driven systems can be designed and developed.
